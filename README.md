# MELMAN Drop — официальные выпуски и обновления

Репозиторий для **публичных установщиков MELMAN Drop для Windows**, заметок о версиях и метаданных подписанных обновлений. Исходный код приложения находится в отдельном **приватном** репозитории и здесь не публикуется.

> **Статус: канал обновлений пока не запущен.** Официальные публичные EXE и манифесты не опубликованы. Не скачивайте файлы, выдаваемые третьими лицами за релизы MELMAN Drop.

## Каналы

| Канал | Назначение | Манифест |
| --- | --- | --- |
| Stable | Проверенные стабильные версии | `channels/stable.json` |
| Beta | Тестовые версии, включаются пользователем отдельно | `channels/beta.json` |

Манифесты создаются **только после подписания, тестирования и ручного утверждения** соответствующей версии. До первого релиза их отсутствие является нормальным. Никаких заглушек или фиктивных цифровых подписей здесь не публикуется.

Каждый утверждённый выпуск будет доступен в разделе **[Releases](https://github.com/Melman-code/melman-drop-releases/releases)**. Приложение получает по HTTPS манифест выбранного канала, проверяет криптографическую подпись установщика Tauri и предлагает установить обновление **только после подтверждения пользователя**.

## Гарантии процесса

- Только установщики, метаданные выпуска, публичные контрольные суммы SHA-256 и подписи Tauri — **никакого приватного кода, ключей, пользовательских настроек, почты и заметок**.
- Отсутствие нового подписанного релиза не должно вызывать автоматическую установку или понижение версии.
- Подпись Tauri защищает in-app обновления, но **не заменяет** сертификат Windows Authenticode и не гарантирует отсутствие предупреждений SmartScreen.
- GitHub Actions artifacts, срок действия которых ограничен, не используются как постоянные ссылки на обновления.
- Публикация релиза и изменение манифеста канала выполняются отдельно от разработки, только после проверки и утверждения.

Этот репозиторий **не является open-source публикацией** приложения MELMAN Drop.
