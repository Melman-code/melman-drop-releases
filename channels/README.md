# Каналы обновлений MELMAN Drop

Здесь будут размещены два файла:

- `stable.json` — проверенные стабильные подписанные релизы.
- `beta.json` — предварительные подписанные релизы для пользователей, выбравших Beta.

**Ни один канал пока не опубликован.** Отсутствие JSON означает, что источник обновлений ещё не активирован. Не создавать пустые/фиктивные JSON-файлы: Tauri updater требует действительную подпись и реальный URL установщика.

Правила публикации:

1. Собрать приватный кандидат, проверить Windows smoke и резервные копии пользовательских данных.
2. Подтвердить исходный закрытый ключ подписи, соответствующий ключу в приложении; **не** сохранять его в GitHub.
3. Собрать подписанный установщик и `.sig`, проверить SHA-256 и подпись.
4. После явного разрешения владельца опубликовать проверенный EXE и `.sig` в GitHub Releases с неизменяемым тегом версии.
5. Убедиться, что конкретный HTTPS URL действительно скачивается (включая проверку из РФ), а содержимое совпадает по SHA-256.
6. Только затем отдельно опубликовать манифест **одного** согласованного канала. Второй канал не затрагивать.
7. На тестовой машине проверить обнаружение, скачивание, подпись, перезапуск и сохранение данных.

**Никаких автоматических публикаций из push/PR в этот репозиторий.** Публичные исходники MELMAN Drop здесь не размещаются.
